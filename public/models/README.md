# Maison Amiral 3D model assets

## maison-human-mannequin.glb

Source: BoQsc/Godot-3D-Male-Base-Mesh (originally orange-juice-games)
Original asset: Original/male_base_mesh.glb

License: CC0 1.0 Universal

The source model is a fully rigged, UV-unwrapped male anatomical base mesh.
Maison Amiral uses it as a sculptural fashion mannequin and applies the relaxed
showroom pose, mannequin material, garment layer, lighting and interaction at
runtime in Three.js.


## maison-tee.glb

Source: 3DAssets.dev — "T shirt on a hanger (Clothing Rail and Wardrobe)"
Model: https://cdn.3dassets.dev/assets/35447/v1/model.glb
License: CC0 1.0 Universal

The garment is served locally with the mannequin. The showroom keeps the largest
garment mesh, discards the retail hanger/helper
geometry at runtime, recolours the shirt with Maison product data, expands its
depth to fit the mannequin, and layers the Maison artwork separately.
